# 复制即动作（macOS）

复制一段内容后，松萝会判断它是不是**命令**或**链接**，并让桌宠冒一个带按钮的气泡。**只有你点了按钮才会做事。**

剪贴板只在内存里判断一次，不记录（和默认关闭的「剪贴板历史」无关）；密码管理器标记为隐藏的内容直接跳过。
两项都可以在 设置 › 桌宠 里关掉。

## 命令 → 终端

- 第一个词是常见命令行工具（git、npm、brew、curl、python、docker、ssh …）或脚本路径（`./x.sh`）才算命令；
  文档里常见的 `$ ` / `% ` 提示符会自动去掉，最多 20 行。
- 点「在终端运行」：iTerm2 正在运行就用它，否则用系统「终端」。首次会弹出系统的「自动化」授权。
- **危险命令运行前再确认一次**：`rm -rf`、`sudo`、`curl … | sh`、`base64 -d |`、`eval`、格式化 / 写磁盘、`chmod 777`、
  `git push --force`、`git reset --hard`、移除隔离标记、修改系统服务、涉及 `~/.ssh` / 钥匙串 等。
  网页可以把恶意命令偷偷放进剪贴板（复制劫持），只运行你信任的来源给出的命令。

## 链接 → 浏览器任务

整段内容是一个 http(s) 链接时，气泡提供：

| 任务 | 做什么 |
|---|---|
| 总结 | 打开页面提取正文，本机模型总结成 3 条要点，显示在对话气泡里 |
| 翻译 | 本机模型把正文翻成中文 |
| 截图存档 | 整页截图 + 正文 Markdown，存到「下载/松萝存档」 |
| 站点菜谱 | 按域名匹配你写的菜谱，在页面里跑一段 JS（最多显示 3 个匹配的菜谱） |

总结 / 翻译后可以一键「喂给营养库」，让输入法学会页面里的术语。

浏览器：装了 **ego lite**（`ego-browser`）就用它（带你的登录状态，在独立的任务空间里操作，不动你正在用的标签页）；
否则连 **Chrome** 的调试端口 `127.0.0.1:9222`，没开就用单独的配置目录（`~/Library/Application Support/Liana/chrome-cdp`）启动一个，
不碰你日常的 Chrome 配置。总结 / 翻译用本机 `llama-server` 模型，不走任何云服务；没装模型时只给出正文开头。

### 菜谱格式

放在 `~/Library/Application Support/Liana/link-recipes/*.json`（设置 › 桌宠 › 打开菜谱目录，会附带一个示例）：

```json
{
  "name": "列出页面里的所有标题",
  "match": ["example.com"],
  "script": "Array.from(document.querySelectorAll('h1,h2,h3')).map(h => h.innerText.trim()).filter(Boolean).join('\\n')",
  "waitMs": 1500
}
```

- `match`：域名，匹配它和所有子域；`"*"` 匹配所有链接。
- `script`：在页面里执行的 JS 表达式，可以返回 Promise；返回字符串直接显示，返回对象按 JSON 显示。
  ego lite 和 Chrome 都能跑（都是在页面上下文里执行）。
- `waitMs`：打开后等多久再执行，默认 1200。
- 菜谱是你自己的本地脚本，会在带登录状态的浏览器里运行，只放你信任的菜谱。
