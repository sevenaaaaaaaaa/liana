# ADR-0004：本地 AI 增强（可选模型，零云 API）

状态：已接受（M1 起步）

## 背景

用户希望候选排序、语音输入、同声传译可以有「小模型级」的智能，但 松萝的隐私
承诺不允许任何云 API：按键、候选、语音都不得离开设备。因此模型必须是本地的，
并且要么随包自带，要么由用户显式下载。

## 决策

按「开销从小到大」分三层，默认全部关闭/最小，逐级可选项：

1. **L0 内置统计模型（零下载，默认开启）**
   - 用户词频 + 用户二元组（上一个上屏词 → 当前候选）重排；
   - 纯内存、无模型文件、内存 < 1MB，不联网；
   - 这就是「自带小模型」的第一档：先让个人习惯生效。

2. **L1 系统本地语音识别（零下载，默认关闭）**
   - macOS：`SFSpeechRecognizer` 且强制 `requiresOnDeviceRecognition = true`；
     若系统/语言不支持端上识别，则**直接禁用并提示**，绝不回退到云端识别。
   - 权限（麦克风、语音识别）在用户首次开启时由系统弹窗授予，可随时关闭。

3. **L2 用户显式下载的开源小模型（默认关闭）**
   - 目录内置：Gemma 3 270M / 1B、Qwen2.5 0.5B / 1.5B、Qwen3 0.6B、Whisper tiny/base/small；
   - 每个模型带 `url + size + sha256 + license + RAM 估算`，下载后校验才可用于推理；
   - 存储：`~/Library/Application Support/Liana/models/<id>/`，可一键删除；
   - **网络只在用户点击下载时建立**，没有遥测、没有模型侧信道请求。

### 内存与推荐策略

- 默认只「推荐开启」RAM 估算 ≤ 系统内存 12.5% 的模型；12.5%~25% 标注「占用较大」；
  > 25% 默认不推荐（仍允许手动启用）。
- UI 明确显示每个模型的内存估算与磁盘占用；启用中的模型显示「禁用」入口。
- L0 永远可用，不因模型缺失而降级；模型不可用时静默回落到 L0，不阻塞输入。

### 推理运行时

- 内核（`crates/*`）保持零第三方依赖、无网络。
- 神经模型推理通过**独立进程 / 可选动态库**（llama.cpp、whisper.cpp）承载，崩溃隔离；
  运行时未安装时仅显示管理界面与说明，不自动下载可执行文件。
- 任何未来计划（同声传译等）都必须走同一目录 + 校验 + 手动启用机制。

### 明确否决

- 云 API、云端语音识别、云端纠错、账号体系；
- 未经用户点击的后台下载 / 更新；
- 在无端上语音识别能力时偷偷回退云端。

## 结果

- 好：隐私承诺不变；用户按需获得更强的候选、语音与翻译能力；模型可审计、可删除。
- 代价：神经模型的体验取决于用户下载与机器性能；同声传译属后续里程碑，
  需要独立的流式推理与断句工程（留待后续版本）。
- 兼容性：模型数据与许可在设置界面与 `crates/ai` 目录中明示；GPL/自定义许可模型
  仅由用户下载，不与 GPL 代码静态链接。
