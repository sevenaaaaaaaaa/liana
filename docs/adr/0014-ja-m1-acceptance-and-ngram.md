# ADR-0014：日语 M1 验收改为字准确率 + 词级 Top-1，并追加 M1.5 语言模型（2026-11-24）

状态：已接受（用户 2026-11-24 决定）

## 背景

M1-8/9/10 已落地（JMdict 剪枝、词性连接矩阵、Viterbi），实测 200 句 UD 日语语料：

- 整句 Top-1 **13.5%**、Top-3 17.5%、字准确率 **83.2%**（23.8 字/句，平均编辑距离 4.0）；
- 45/200 句只错 1 字，75/200 句错 ≤2 字；
- 规划第 8 节止损条件 3（3 轮调优后整句 Top-1 <75%）已触发。

整句 85% 对一个「3 万词条 + 词性 bigram」的统计模型不现实：它要求字准确率约 99%，
需要词级/字级 n-gram 甚至神经语言模型。当前主要错误是同词性同音词
（初めて/始めて、新鮮/深セン、物/仏画），正是词级上下文的缺口。

## 决策

1. M1 验收改为：
   - **字准确率 ≥90%**（200 句整句语料，按字数加权，1 − 编辑距离/总字数）；
   - **词级 Top-1 ≥85%**（UD dev/test 抽 500 个词，输入假名读音，首选等于原词形；
     该指标测词表消歧，不测上下文，定义写在 `xtask/data/corpus/README.md`）。
2. 追加 **M1.5**：词级/字级 n-gram 语言模型，用于 Viterbi 重排，目标是把字准确率从
   83.2% 提到 90% 以上。
3. 整句 85% 的口径**不删除**，移到 M2 之后作为长期目标；每次评测继续打印，只不作为
   M1 的准出门槛。

## 备选方案与否决理由

- **保留整句 85%**：需要 3–5 人日的语言模型工作，且仍不保证达标；会阻塞 M2/M3。
- **按止损降级成「常用汉字 + 词干」**：降低能力上限，不解决同音词问题，用户价值更差。

## 后果

- `xtask eval-corpus --lang ja` 继续输出三项（整句 Top-1/Top-3/字准确率）；
- 新增 `xtask eval-words --lang ja` 与 `liana-ja-words.tsv`；
- M1.5 的数据（n-gram）继续按 CC BY-SA 4.0 / CC BY 2.0 FR 署名，写进
  `crates/ja/data/SOURCES.md`；
- CI 是否加硬门槛等 M1.5 达标后再定，避免把红闸门留在 main 上。
