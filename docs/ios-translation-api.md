# iOS 键盘：候选译文与云端翻译

候选条右侧的译文芯片（例如 `EN 你好`）就是中文候选的多语言入口：

- **点按**：把译文插入当前输入框。
- **长按**：目标语言（EN / 日 / 한 / FR / DE / ES / RU）、云端开关、导入配置、刷新、隐藏。

## 两层翻译

1. **本地词表（默认）**：读随包 `mobile.sqlite` 的 `gloss` 表，逐词对照，不联网、立即出结果；命中率一般。
2. **云端 API（可选）**：任意 OpenAI 兼容的 `/chat/completions` 服务，整句翻译，准确率明显更高。

## 开启云端

1. 准备一段 JSON，复制到剪贴板：

```json
{
  "base_url": "https://api.openai.com/v1",
  "model": "gpt-4o-mini",
  "api_key": "sk-...",
  "target": "en",
  "enabled": true
}
```

2. 键盘里长按译文芯片 → **导入配置**。
3. 芯片会立刻改用云端结果；失败时自动回退本地词表，不会空着。

`base_url` 必须是 `https`。API Key 只写进键盘的 Keychain（`dev.liana.keyboard.translation`），不写 UserDefaults，也不会进日志。

## 隐私边界

- 默认关闭云端；关掉后完全不发网络请求。
- 开启后只发送**当前首选候选那一小段文字**（≤200 字），不发送输入历史、不发送上下文。
- 需要「允许完全访问」才能读剪贴板配置和联网。

## 关闭

长按芯片 → **云端 关**：立即停止请求，回到本地词表。
