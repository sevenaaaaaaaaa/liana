# 松萝使用指南

> 核心定位 · Features · 具体用例。写给刚开始用 松萝、在意输入隐私的用户
> (律师 / 医生 / 记者 / 处理敏感信息的每个人),也是官网素材源之一。
> AGPL-3.0 开源,214 项内核测试全绿,一切可审计。

---

## 核心定位

输入法是你在每台设备上用得最多、也最敏感的软件——你打的每一个字都经过它。绝大多数输入法把按键、词频、习惯送上云端换「智能」;松萝把方向反过来:**所有智能都在本地产生,云端一个字节都拿不到**。没有账号,没有「匿名上报」,没有联网纠错。

不装云不等于不专业:Rust 写的 13 个纯逻辑 crate,全拼 / 双拼 / 英文 / 日语罗马字,Viterbi 整句转换,20 万词条,214 项内核单元测试全绿。它也会学你——按应用记忆中英切换、用户词频与短语学习,统计模型不到 1 MB,只存本机;选词、纠错、喂食还会让它持续进化(见下文知你自进化)。

松萝是林下 Understory 矩阵 Studio 层的隐私输入周边(**不是 Flow,不走业务线**):本地工具 + 引流,完全独立运行,不依赖任何 Flow 产品;当越来越多文字经由 AI 生成与处理,输入这个最敏感的入口更不该把数据交给云。

## Features(按你将真实用到的顺序)

### 1. 第一天:构建、安装、启用
`./platforms/macos/build.sh` 构建 → `./platforms/macos/install.sh` 装到输入法目录;再到「系统设置 → 键盘 → 输入法 → + → 中文(简体)→ 松萝」启用。装完可以断网用——安装包本身可断网使用。

### 2. 专业输入引擎
全拼(20 万词条 + Viterbi 整句 + 前缀补全)· 双拼 ×3(小鹤 / 微软 / 自然码)· 英文(2 万词 + 词频)· 日语罗马字;候选窗是 Liquid Glass 玻璃质感。

| 输入方案 | 状态 |
|---|---|
| 全拼 · 双拼(小鹤 / 微软 / 自然码)· 英文 · 日语罗马字 | ✅ |
| 中英混输 · 表情 `aa` · 符号 `u` · 简繁转换 | ✅ |
| 日语假名 → 汉字(JMdict + Viterbi) | ⏳ M2 |

### 3. 顺手的小输入功能
中英混输(候选融合英文,大写即英文意图)· 表情模式(连按 `aa`)· 符号输入(`u` 前缀)· 简繁转换(OpenCC 词表)。

### 4. 按应用记忆中英切换
本地统计模型学习你的切换习惯:Shift 一按即学——终端自动英文,微信自动中文,不用每次手切。

### 5. 知你自进化(越用越懂你)
选词 +1、选后删除 −2、删除后重选 +1.5——你的纠错行为就是教材;菜单「喂它一段」把截图(Vision 端上 OCR,零网络)或文档里的专有名词提炼成「营养库」,甲方名字教一次就能打出来;傍晚小结对比「学习开 vs 关」的命中率差值,学习有没有用数字说话。全部账本只在本机,逐条可忘、一键清空。

### 6. 本地 AI 增强(可选,零云 API)
L0 知你自进化默认开启(纠错即教学 + 营养库 + 反事实评估);L1 端上语音边说边落字;L2 小模型(Gemma / Qwen / Whisper)一键下载、sha256 校验、本机运行、随时删除;同声传译走 llama.cpp 独立进程,仅 127.0.0.1 回环。不支持端上的能力直接禁用,绝不回退云端。

### 7. 权限中心 + 零内容统计
全部敏感能力集中一处:碰什么数据、存在哪、怎么删,关闭即清空。统计只给你速度、纠错、节省击键——只计次与秒,绝不记录任何按键内容。

### 8. 有生命的桌宠(可选)
默认形象为内置 VRM 样例(离线,无需下载);可下载更多 VRM 形象,或导入 VRoid Studio 自捏的 VRM 角色:跟随鼠标注视、眨眼、弹簧骨物理;点击即中英切换,跨屏跟随。气泡只报本机任务,永不承载付款与营销。

### 9. 插件 = 数据包
皮肤 / 桌宠 / 词典都是声明式数据包:零代码、权限白名单制、装包即放目录;无在线市场、无自动更新、无可执行代码。

## 具体用例(可直接照抄的实战路径)

### 用例 A · 敏感环境输入(律师 / 医生 / 记者)
1. 构建并安装,在系统设置里启用松萝;
2. 断开网络写半小时文档,确认输入、联想、学习全部正常——引擎与词典全在本机;
3. 打开权限中心,逐项检查敏感能力状态,用不到的直接关闭(关闭即清空);
4. 日常写合同 / 病历 / 采访记录,按应用记忆自动切中英文;
5. 用得越久越顺手:词频、短语与知你账本只存在本机,选错了删掉重选,它下次就不犯。
**结果**:最敏感的 keystrokes 从此不出设备,打字顺手程度不打折。

### 用例 B · AI 场景下的输入隐私(重度 AI 用户)
1. 关掉所有云输入法的「联网优化」,换上松萝;
2. 需要语音输入时,启用端上语音听写(L1),文字边说边落在本机;
3. 想要更强联想,从 L2 显式下载一个小模型,sha256 校验后本机运行;
4. 哪天不想要了,在权限中心删除模型,磁盘不留残余。
**结果**:向 AI 提问的每一句,只在你按下回车那一刻才离开设备——而且是由你决定。

### 用例 C · 做一套自己的皮肤或桌宠包(爱折腾的用户)
1. 跑 `cargo run -p xtask -- plugin new --kind skin --id skin-mine --name 我的皮肤`;
2. 按生成的数据包结构改配置与素材,不需要写代码;
3. `cargo run -p xtask -- plugin check plugins/skin-mine` 校验;
4. 包放进插件目录即生效,分享给朋友也只是拷文件;
5. 想做桌宠或词典包,换 `--kind pet` / `--kind dict`,流程一样。
**结果**:输入法第一次可以像换壁纸一样换装,且装的东西永远是数据而非程序。

## 常见问题

**为什么没有云词库、没有云联想?**
这是隐私承诺的代价,也是选择:零遥测、零云 API,词库更新随版本发布。代价换来的是按键数据物理上无法上云。

**多设备同步什么时候能用?**
局域网 P2P 同步(扫码配对、端到端加密)的协议与合并内核已实现并有测试;QUIC/TLS 传输层与配对 UI 排在 M3,当前版本同步默认关闭。

**支持 Windows / Android / iOS 吗?**
目前仅 macOS(macOS 13+,M1 里程碑进行中);Windows / Linux 在 M3,移动端 M4,鸿蒙 M5,均未落地。

**日语能打汉字吗?**
罗马字 → 假名已可用;假名 → 汉字(JMdict + Viterbi)在 M2,尚不可用。

**macOS 26 上启用失败?**
macOS 26 仅收录有效签名输入法;ad-hoc 构建需注销重登录,或先配置签名身份再构建。
