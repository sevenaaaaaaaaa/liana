# iOS 体验规范 · build 7

此文件定义 iOS 键盘与主 App 的黑白体验，覆盖统一设计语言 v1 中的 iOS 颜色、动效和工具入口。macOS 等其他平台沿用原规范。实际色值位于 `platforms/ios/Shared/LianaUI.swift`。

## 颜色与层级

| 语义 | 雾白 | 石墨黑 |
|---|---|---|
| App 背景 | `#F5F5F2` | `#101112` |
| 卡片 | `#FFFFFF` | `#1B1D1F` |
| 键盘底色 | `#E5E7E6` | `#17191B` |
| 普通按键 | `#FFFFFF` | `#303335` |
| 功能按键 | `#CFD3D1` | `#222527` |
| 按下反馈 | `#C4C8C7` | `#505557` |
| 主文字 | `#191B1D` | `#F3F3EF` |
| 次文字 | `#64686A` | `#B3B7B9` |
| 主操作／首候选 | `#202224` | `#EDEEE9` |
| 主操作文字 | `#FFFFFF` | `#17191B` |

仅用一档反差表达主操作。其他候选减轻背景；错误、禁用和选中状态同时用文字、图标或原生状态表达。主次文字的必要配对均检查 4.5:1 对比度。原生权限弹窗保持系统行为。

采用系统字体：字母键 20pt、功能键约 15pt、候选默认 17pt；候选仍可调 14–24pt。App 正文和标题支持 Dynamic Type，紧凑控件适度限制最大字号并允许换行。编辑框按可见行数随字号增高，长文在框内滚动。

## 键盘

- 顶部只保留工具、外接设备、布局三个常用入口。工具打开后切换为键盘图标，选中状态可见；输入时提供组合串和取消按钮。
- 空闲候选栏用于常用标点；输入后切换为候选，首候选反差突出。候选更新不做位移动画。
- 手机横屏将组合串、候选与工具合到一行；输入／上屏不会反复改变键盘高度。平板保留两侧键组与中间候选／光标区。
- 保持至少 44pt 键高，字母宽度沿用设备键距；工具、光标与其他常用操作有至少 44pt 热区。用户预设和精细调节不会清掉待选文字。
- 候选区与字母区相隔 4pt，底部固定留 8pt，再叠加用户留白和系统安全区。输入容器通过自适应高度接受这些尺寸，不靠挤压底行补偿。
- 拖动顶部工具组可以改高度与入口位置；预设和滑块提供手势之外的操作方式。VoiceOver 保留增高／降低动作。

工具分为「输入、表情、同步、词库」，每类保留具体操作，不再堆成长清单。输入方案可在键盘内直接选择，避免系统弹出菜单空间不足。常用布局先给标准、单手、宽松预设，再展开精细调节；主题、触感、字形和全部原有参数保留。

## 动效与触感

| 场景 | 行为 |
|---|---|
| 按下 | 立即改变表面，不移动键位、不重建键盘 |
| 松开 | 100ms 缓出恢复 |
| 面板打开 | 180ms 缓出，最多 6pt 位移 |
| 面板关闭 | 100ms，最多 3pt 位移 |
| 主题预览／切换 | 160ms 交叉淡化 |
| 工具分类 | 轻量整块切换，不逐项飞入 |
| 录音音量 | 约 80ms 更新，来自实际输入音频的 RMS |
| 减少动态效果 | 跳过位移／过渡；录音条保持静态指示 |

普通按键使用较轻触感，选词确认稍强；触感可独立关闭。解码、词库读取与学习继续放在串行后台队列；平板候选按钮也复用。移动光标前先完成待选内容的提交，避免后台提交落到错误位置。

## 主 App 与连续操作

首页提供键盘外观预览、启用入口、输入工具、Mac 连接及真实试打；预览不伪装成对键盘偏好的远程修改。

输入工具的四个分类固定在顶部，正文单独滚动。切换分类回到对应内容顶部，编辑文字时避开键盘。语音、词库、表情和同步分别显示清楚的状态及下一步操作。

- 语音只在主 App、用户主动开始后录制，使用设备端中文识别。停止时等待尾句完成；识别期间不允许编辑覆盖。已有草稿保留，新录音接在草稿之后。草稿保存在本机，可清空并在当前页面撤销。
- 文字与 GIF 复制时，同时提供标准粘贴类型与松萝接收类型：可直接粘贴到支持的 App，也可回键盘接收／收藏。交接仅本机保留 10 分钟。配对密钥与词库只提供松萝接收类型，不混进普通文字粘贴。
- 词库解析期间禁用复制，保留已有成功结果。新请求取代旧请求，旧回调不会覆盖新请求的状态或词库。
- Mac 页面突出扫码配对、连接和发送的顺序；未配对时不显示多余的断开／忘记入口。错误二维码保持相机打开，提示重新扫描。现有配对许可与 TLS 传输规则保持一致。

## 验证范围

原有输入、九宫格／双拼／五笔／手写／滑行、BLE、词库和跨设备协议回归继续执行。补查明暗主题、375pt 手机、932pt 横屏、1024pt 平板、大字号、自适应高度、按下反馈、预设保留组合串、直接粘贴数据类型、配对内容隔离、草稿恢复／撤销、异步提交后移动光标等。

实际 App 进程验证冷启动、重启、Mac 入口与工具四类切换，并保留截图。模拟器验证不代替实体 iPhone 的触感、录音、内存与跨设备验收。
