# 威胁模型（我们防什么、不防什么）

隐私产品的可信度来自**说清边界**。以下每条都可以用抓包、`tcpdump`、防火墙规则或读代码验证。

## 1. 防护目标

| # | 威胁 | 对策 | 验证方式 |
|---|---|---|---|
| T1 | 输入内容被上传/售卖 | 内核零网络代码；前端不链接网络库 | 抓包（应只有 0 出站包）；`cargo tree` 无网络依赖 |
| T2 | 遥测/设备指纹 | 不采集、不生成设备 ID；本机统计只存内存 | 代码审计；文件系统 diff |
| T3 | 词库/习惯被云端画像 | 用户词只在本机磁盘 + 自己的设备间同步 | 检查存储文件；同步抓包只见局域网 |
| T4 | 同步被中间人窃听/篡改 | 配对时交换长期公钥指纹 → 后续 QUIC 上 TLS 1.3 双向认证，证书固定；载荷再套一层 AEAD | 配对指纹比对；证书 pin 校验失败即断连 |
| T5 | 服务端被入侵导致数据泄露 | 架构上没有服务端 | 不存在该组件 |
| T6 | 磁盘被翻看导致词库泄露 | 用户词/剪切板加密落盘，密钥在 OS 钥匙串 | 明文 grep 存储目录应无结果 |
| T7 | 更新通道投毒 | 不自动检查、不后台下载：只有用户点「检查更新 / 立即更新」才连 GitHub（api.github.com 与 Release 下载地址），不上传任何数据；安装包必须与同一 Release 的 `.sha256` 一致，否则整个放弃；新包 bundle id 不同或需要管理员权限时不自动替换；发布产物附哈希，用户可复现构建 | 断网时「检查更新」报错且无其他出站；篡改 DMG 后安装被拒；抓包只见 GitHub |
| T8 | 本地 AI 模型/下载被投毒 | 模型清单内置 url + size + sha256，下载后校验失败即删除；不接受可执行文件下载；推理运行时另行发布并签名 | 检查下载文件 sha256；代码审计下载路径 |
| T9 | 语音被上传云端 | 语音识别强制端上（`requiresOnDeviceRecognition`），不支持端上则禁用而非回退；麦克风仅用户开启时占用 | 断网可用性验证；系统权限面板 |

## 2. 明确不防（诚实声明）

| 威胁 | 说明 |
|---|---|
| 操作系统级键盘记录 | 输入法必须经 OS 输入框架收键；同机上的恶意软件/内核级监控无法在应用层对抗 |
| 被攻破的操作系统 / 越狱环境 | 内存中的按键、钥匙串访问都可能被截获 |
| 恶意输入法竞争者读取屏幕 | 候选窗内容属于屏幕内容，不是本产品能控制的边界 |
| 硬件侧信道（对电磁/功耗） | 超出软件范围 |
| 用户主动导出明文 | 导出功能会显式告知「将以明文保存」 |

## 3. 权限最小化清单

| 平台 | 申请 | 不申请 |
|---|---|---|
| macOS | 输入法安装（用户手动拖入 `~/Library/Input Methods`）、无网络 entitlement；可选：麦克风 + 语音识别（仅在用户开启语音输入时） | 辅助功能、屏幕录制、完全磁盘访问 |
| iOS | 键盘扩展基础权限 | **不申请 Full Access**（因此无网络） |
| Android | 输入法服务；同步时用前台服务 + 局域网权限 | 存储全盘、通讯录、位置 |
| Windows | TSF 注册 | 开机自启以外的常驻服务 |
| Linux | Fcitx5 addon | root 权限 |

AI 增强的网络与权限边界：默认零网络；只有用户在「AI 增强」中点击下载模型时才建立 HTTPS 连接
（目标与 sha256 在界面明示）；语音能力必须端上执行。长句 AI 重排只连 127.0.0.1 上用户自装的 llama-server。

在线更新（macOS）：同样默认零网络，只在用户于「关于」页或输入法菜单点「检查更新」时请求 GitHub Releases，
见 T7。

## 4. 数据生命周期

```
按键 → 内存 buffer（提交即清，不落盘、不入日志）
选词 → 内存 UserModel（M1 起：加密文件 ~/…/user.model.enc）
语音 → 仅用户开启时采集；端上识别，音频不落盘、不上传
AI 模型 → 用户显式下载的开源权重，存放于 ~/…/Liana/models/，可一键删除
剪切板 → 默认关闭；开启后仅保留最近 N 条（默认 200），加密落盘，可一键清空
整句搭配模型 → ~/…/Liana/base.lm：随安装包分发的公开语料统计数据，只读，不含任何用户数据
应用名词包 → ~/…/Liana/dicts/apps.tsv：只读已装应用包里的名字（不读应用数据），不含任何输入内容，明文，删除即失效
同步 → 仅配对设备，局域网，TLS 1.3 + AEAD；同步内容为 op-log，不含原始按键流
```

- 崩溃日志：默认关闭；开启时明确提示包含哪些字段。
- 卸载：删除应用即删除一切（无云端残留）；macOS 提供 `uninstall.sh` 清理用户数据目录。

## 5. 威胁模型变更流程

任何引入网络代码、新增权限、改变落盘范围的 PR，必须先改本文件并在 PR 描述中给出验证步骤。
