# 松萝 Liana

**隐私优先的跨平台输入法 — 纯本地引擎 · 零服务器 · 零遥测**

> **品牌小记**:松萝,附松而生、随枝而长的地衣;Liana,热带雨林里的藤蔓。二者都安静、都随宿主生长——这正是松萝的自我期许:不打扰你,但一直在随你进化。

打字这件事不需要交给云:引擎、词典、学习全部在你设备上跑;跨端同步走局域网 P2P 端到端加密,没有账号,没有"匿名上报"。

> **三个承诺**
>
> 🔒 **你的按键永远不离开你的设备** —— 引擎、词典、学习全部本机运行,安装包可断网使用
> 🙈 **零遥测、输入零云端** —— 没有"匿名上报",没有"联网纠错",本地 AI 模型由你显式下载（唯一的例外是桌宠形象工坊里可选的「AI 补全表情」：用你自己配置的图像服务和 Key，点了才上传那一张「平时」图）

## 这是什么

输入法是你在每台设备上用得最多、也最敏感的软件——你打的每一个字都经过它。市面上绝大多数输入法把按键、词频、习惯送上云端换"智能";松萝把方向反过来:**所有智能都在本地产生**,云端一个字节都拿不到。

它首先是一个专业输入引擎:Rust 写的 13 个纯逻辑 crate,全拼 / 双拼 / 英文 / 日语罗马字,Viterbi 整句转换,20 万词条,215 项内核单元测试全绿。它也会学你:按应用记忆中英切换(终端自动英文、微信自动中文)、用户词频与短语学习,这些统计模型不到 1 MB,只存在本机。

它不止被动学习,还会主动进化:每一次选词、删除、重选都是教学信号——选了又删是最强的负反馈;截图或文档喂给它(菜单「喂它一段」,Vision 端上 OCR,零网络),专有名词沉淀成「营养库」,你的甲方名字教一次就能打出来;傍晚小结对比「学习开 vs 关」的反事实命中率,学习有没有用,数字说话。全程不升级软件、不上传任何东西(见下方核心能力与 [ADR-0008](docs/adr/0008-self-evolution-framework.md))。

它不装云,但不排斥 AI:端上语音听写、Gemma / Qwen / Whisper 小模型、同声传译,都是你**显式下载、本机运行、可随时删除**的可选项——不支持端上就禁用,绝不回退云端。

## 核心能力

- **专业输入引擎** — 全拼(20 万词条 + Viterbi 整句 + 前缀补全)· 双拼×3(小鹤 / 微软 / 自然码)· 英文(2 万词 + 词频)· 日语罗马字;中英混输、表情模式(`aa`)、符号输入(`u` 前缀)、拆字输入(`uu` + 部件拼音，不会读也能打)、简繁转换(OpenCC 词表)
- **按应用记忆中/英** — 本地统计模型学习你的切换习惯:Shift 一按即学,终端自动英文、微信自动中文
- **知你自进化** — 纠错即教学、喂一段学一堆、学习效果可验证;不升级软件自己变准,详见[下方专节](#知你自进化)
- **本地 AI 增强(可选,零云 API)** — L0 知你自进化(纠错即教学 + 营养库 + 反事实评估,默认开启)· L1 端上语音边说边落字 · L2 小模型一键下载(sha256 校验,本机运行)· 同声传译(llama.cpp 独立进程,仅 127.0.0.1 回环)
- **有生命的桌宠** — 默认形象为内置 VRM 样例(离线,无需下载);VRM 3D 渲染器(跟随鼠标注视 / 眨眼 / 弹簧骨物理),可下载更多 VRM 形象或导入 VRoid Studio 自捏角色;点击即中英切换,跨屏跟随
- **插件 = 数据包** — 皮肤 / 桌宠 / 词典,声明式零代码执行,权限白名单制,装包即放目录;无在线市场、无自动更新、无可执行代码
- **权限中心** — 全部敏感能力集中展示:碰什么数据、存在哪、怎么删,关闭即清空
- **零内容统计** — 速度、纠错、节省击键、最长发呆、卡路里——只计次与秒,绝不记录任何按键内容
- **局域网 P2P 同步(默认关闭)** — 设备间扫码配对(Ed25519 + 一次性配对码 + 6 位校验码防中间人),mDNS 发现、端到端加密,没有服务器没有账号;用户词与剪切板历史 ChaCha20-Poly1305 加密落盘,密钥在系统钥匙串

桌宠不是贴图:它是**皮肤资产 + 渲染器**([ADR-0007](docs/adr/0007-desktop-pet-renderers.md))——内置 VRM 样例零下载,VRM 3D 渲染器本地离线运行(WKWebView + three.js + three-vrm),输入焦点在哪块屏幕就在哪块屏幕互动;气泡只报本机任务,**永不承载付款与营销**([ADR-0006](docs/adr/0006-notifications-and-stats.md))。

## 知你自进化

云输入法优化「平均人」,松萝优化「你」。群体词频永远回答不了「在这个应用、这个话题、这个时段,`xian` 该是先、县还是西安」——答案不在人群里,在**你 + 此刻的上下文**里([设计见 ADR-0008](docs/adr/0008-self-evolution-framework.md)):

| 机制 | 做法 |
|---|---|
| **纠错即教学** | 选词 +1 · 数字键越级选 +0.6 · 删除后重选 +1.5 · **选了又删 −2(最强信号)**——云输入法把你的删除当噪声,我们当教材 |
| **喂食式学习** | 菜单「喂它一段」:截图(Vision 端上 OCR,零网络)/ 文档 / 粘贴文本 → 本地提炼专有名词进「营养库」——你的甲方名字、项目术语,教一次处处可用,逐条可忘 |
| **学习不掀桌** | 重排只在同覆盖层级内换位、单词修正封顶 ±3、两次观察以内不说话——学习只能微调排序,词频与整句概率仍是基本盘 |
| **可解释、可验证** | 每个词为什么排前说得清;傍晚小结对比「学习开 vs 关」的**反事实首选命中率**,学习有没有用,数字说话 |

全部信号、账本、营养库只在本机,加密落盘、随备份搬走、一键清空;可选的本机 Gemma(零云)只增强喂食文档的术语与主题提炼,**决策始终走账本**。

**输入方案与状态**

| 方案 | 状态 |
|---|---|
| 全拼(20 万词条 + Viterbi 整句 + 前缀补全)· 双拼(小鹤 / 微软 / 自然码) | ✅ |
| 英文(2 万词前缀补全 + 词频)· 日语(罗马字 → 假名) | ✅ |
| 中英混输(候选融合英文,大写即英文意图)· 简繁转换(OpenCC 词表) | ✅ |
| 表情模式(连按 `aa`)· 符号输入(`u` 前缀) | ✅ |
| 日语(假名 → 汉字,JMdict + Viterbi) | ⏳ M2 |

## 快速上手

### 普通用户（最简单，零命令行）

1. 双击 **松萝安装器.app**（或从 DMG 打开）
2. 点 **「安装松萝」** —— 自动装到 `~/Library/Input Methods`，进度逐项可见
3. 按提示打开 **键盘设置**：点 **+** → **中文（简体）** → **松萝**，即可用
4. 打字时按 **⌃`**（Control + 反引号）打开**功能面板**：截图学习、语音输入、同声传译、桌宠、喂它一段、剪切板一键直达；
   全部配置在输入法菜单 › **松萝设置…**（侧栏分区，macOS 26 上为 Liquid Glass）

> 若「松萝」不在列表里，**注销并重新登录一次**即可（macOS 对全新输入法需重新扫描）。
> 首次打开若被 Gatekeeper 拦下：右键安装器 → **打开**（免此步骤需 Developer ID 公证版本）。

不想自己构建？[GitHub Releases](https://github.com/sevenaaaaaaaaa/liana/releases) 有现成安装包（tag 推送自动构建）：**macOS** DMG（含安装器；ad-hoc 签名未公证，首次打开右键 → 打开）、**Android** 签名 APK、**Linux** ibus 引擎 tarball（`sudo ./install.sh`）。iOS / Windows / 鸿蒙尚在骨架阶段，暂不出包。

### 从源码构建（开发者）

```bash
cargo test                                  # 内核 215 项测试,全绿是合并底线

# macOS 输入法(Universal:Intel → M 系列,macOS 13+)
./platforms/macos/build.sh                  # 构建自动选用可用签名身份
./platforms/macos/install.sh                # 安装到 ~/Library/Input Methods
```

发布分发:`./platforms/macos/dist.sh`(签名 → Hardened Runtime → 公证 → DMG → staple);签名三级降级如实标注产物,绝不假装可分发。

做皮肤 / 桌宠包不需要会写代码:

```bash
cargo run -p xtask -- plugin new --kind skin --id skin-mine --name 我的皮肤
cargo run -p xtask -- plugin check plugins/skin-mine
```

## 平台与当前状态

六端共用同一 Rust 内核（`liana.h` C ABI，内核零平台改动）：

| 平台 | 集成 | 状态 |
|---|---|---|
| macOS | InputMethodKit + Liquid Glass 候选窗 | ✅ 日常可用（v0.1.0 起） |
| Android | InputMethodService + JNI 垫片（Kotlin） | ✅ APK 构建成功，待真机验收 |
| iOS | 键盘扩展 + 静态链接（Swift） | ✅ 模拟器构建/启动验证通过，待真机 |
| Linux | IBus 引擎（Python/GI + ctypes） | ✅ 引擎完成，绑定层冒烟 11/11，待实机 |
| HarmonyOS NEXT | InputMethodExtensionAbility + NAPI | 🟡 脚手架 + OHOS 静态库就绪，待 DevEco 联调 |
| Windows | TSF COM DLL（C++ 壳 + Rust 静态内核） | 🟡 骨架 + 按键流接通，组合上屏待调试 |

各端构建入口：`platforms/<平台>/build.sh`（Windows 为 `build.cmd`）。

## 定位说明

**松萝不是 Flow,也不走 Flow 家族的业务线**——它是林下 Understory 产品矩阵**第三层:Studio 套件**的周边产品,解决的是 AI 时代的输入与隐私输入:当越来越多文字经由 AI 生成与处理,输入法这个最敏感的入口更不该把数据交给云。矩阵的分层是:

- **OpenFlow = 入口层**:TIPS all-in-one,让一人团队(OPC)与中小团队低门槛完成数字化 + AI 化。
- **Flow 家族 = 进阶层**:MFlow / inFlow / UserLoop / PayFlow / LearnFlow / WebsFlow 按需进阶,各自深耕一个业务场景。
- **Studio 套件 = 本地工具层**:松萝、ThirdC(知识工作台)、V2HTML(视频⇄内容引擎)、ZeroZen(广告净化)等,偏本地工具、吸引更多用户,长期方向是**作为工作台打通所有 Flow 产品**。

与 OpenFlow 矩阵是**松耦合**:松萝完全独立运行,不依赖也不对接任何 Flow 产品即可完整使用;共享设计契约(玻璃候选窗、同源设计令牌),未来作为矩阵在输入侧的常驻入口。

## 当前边界

- **目前只有 macOS 可用**(macOS 13+,M1 里程碑进行中);Windows / Linux / 移动端 / 鸿蒙按 M3–M5 排期,未落地
- **日语只有罗马字 → 假名**:假名 → 汉字(JMdict + Viterbi)在 M2,尚不可用
- **跨端同步传输未完成**:协议与合并内核(HLC + LWW/CRDT)已实现并有测试,QUIC/TLS 传输层与配对 UI 在 M3;当前版本同步默认关闭
- **不进输入法商店、无云词库**:安装靠 DMG / 脚本,词库更新随版本发布;这是隐私承诺的代价,也是选择
