# 固定语料评测集（精准度专项 P0）

`xtask eval-corpus` 消费的语料目录。文件格式：

- **2 列**：`全拼<TAB>句子`（Sime cases 格式；全拼无声调、无音节分隔）
- **3 列**：`类别<TAB>全拼<TAB>句子`（自建种子集）

## 文件与来源

| 文件 | 规模 | 来源与许可 |
|---|---|---|
| `sime-cases.1.txt` | 1999 句 | [Ismantic/Sime](https://github.com/Ismantic/Sime) `pipeline/cases.1.txt`，Apache-2.0。原文件经重命名（加 `sime-` 前缀），内容未改动 |
| `sime-cases.2.txt` | 2000 句 | 同上（`pipeline/cases.2.txt`） |
| `liana-seed.tsv` | 120 句 | 自建（6 类：聊天日常 / 工作办公 / 科技数码 / 新闻时事 / 成语俗语 / 口语感叹），随仓库维护 |

## 口径

- 每句独立会话（隔离个人数据、不跨句学习），对齐水杉评测协议；
- 全拼 ≤64 字母（内核 `MAX_INPUT_CHARS`）逐句整体解码 = **整句口径**；
- 更长的句子走「喂 60 字母 → 空格选首选 → 续打」的**分段口径**，单独统计不与整句混算；
- 指标：Top-1 句准确率（完全匹配）、Top-3 句命中、字准确率 = 1 − 总编辑距离/总字数（按字数加权）。

外部参照（2026-04 白霜作者公开评测，246 句）：白霜+n-gram 句准确率 71.54%、微软拼音黑盒 67.89%、手心 71.14%；雾凇+万象 64.23%。我们的目标线是 71%。
