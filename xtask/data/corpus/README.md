# 固定语料评测集（精准度专项 P0）

`xtask eval-corpus` 消费的语料目录。文件格式：

- **2 列**：`全拼<TAB>句子`（Sime cases 格式；全拼无声调、无音节分隔）
- **3 列**：`类别<TAB>全拼<TAB>句子`（自建种子集）

## 文件与来源

| 文件 | 规模 | 来源与许可 |
|---|---|---|
| `sime-cases.1.txt` | 1999 句 | [Ismantic/Sime](https://github.com/Ismantic/Sime) `pipeline/cases.1.txt`，Apache-2.0。原文件经重命名（加 `sime-` 前缀），内容未改动 |
| `sime-cases.2.txt` | 2000 句 | 同上（`pipeline/cases.2.txt`） |
| `liana-seed.tsv` | 120 句 | 自建（6 类：聊天日常 / 工作办公 / 科技数码 / 新闻时事 / 成语俗语 / 口语感叹），随仓库维护 |

## 口径

- 每句独立会话（隔离个人数据、不跨句学习），对齐水杉评测协议；
- 全拼 ≤64 字母（内核 `MAX_INPUT_CHARS`）逐句整体解码 = **整句口径**；
- 更长的句子走「喂 60 字母 → 空格选首选 → 续打」的**分段口径**，单独统计不与整句混算；
- 指标：Top-1 句准确率（完全匹配）、Top-3 句命中、字准确率 = 1 − 总编辑距离/总字数（按字数加权）。

外部参照（2026-04 白霜作者公开评测，246 句）：白霜+n-gram 句准确率 71.54%、微软拼音黑盒 67.89%、手心 71.14%；雾凇+万象 64.23%。我们的目标线是 71%。

## 首版基线（2026-11-03）

`xtask eval-corpus`（词典 232k + 生产 base.lm）：seed 65.8% / cases.1 62.5% / cases.2 42.2%（含噪声，仅作回归对照）；整句子集合计 52.4%，字准确率 87.6%。
注意：cases.2 含「放佛」「佢」等噪声句，目标线对比以 cases.1 + seed 为主。

## 日文语料（M1 / M1.5）

| 文件 | 规模 | 来源与许可 |
|---|---|---|
| `liana-ja.tsv` | 200 句 | 由 `UD Japanese-GSD` dev+test 派生（CC BY-SA 4.0）：假名读音 → 原句表记；生成脚本 `crates/ja/tools/make_eval_corpus.py` |
| `liana-ja-words.tsv` | 500 词 | 同上（CC BY-SA 4.0）：假名读音 → 原词形 + 词性；按语料出现频次取词，生成脚本 `crates/ja/tools/make_word_eval.py` |

口径：

- 整句：第二列是**假名**（不是罗马字），`xtask eval-corpus --lang ja` 直接走
  `liana_ja::decode_kana`，不经过 feed；指标为整句 Top-1 / Top-3 / 字准确率。
- 词级：`xtask eval-words` 单独测「一个词的首选是否等于原词形」；词典里标注为
  通常假名书写的词（如 居る/いる），首选读音也算对。样本按使用频次取，不按词型均匀取。

验收口径（ADR-0014，用户 2026-11-24 确认）：**字准确率 ≥90% + 词级 Top-1 ≥85%**；
整句 Top-1 85% 移到 M2 之后作为长期目标，每次仍打印但不作 M1 门槛。

当前基线（2026-11-24，3 万词条 + 词性 bigram + 字符 4-gram 重排，LM 权重 30）：

- 整句：Top-1 **22.5%**、Top-3 26.5%、字准确率 **85.8%**（未达 90%）；
- 词级：Top-1 **85.2%**、Top-3 93.0%（已达标）。

整句全对的要求远高于字准确率；剩余错误主要是同词性同音词（初めて/始めて、
新鮮/深セン、物/仏画），词性 bigram + 字符重排的天花板约在 86% 字准确率。

## 混输语料（M2）

| 文件 | 规模 | 来源与许可 |
|---|---|---|
| `liana-mix.tsv` | 50 句（中 15 / 日 15 / 英 15 / 混排 5） | 自建；`xtask eval-corpus --lang mix` |

口径：输入按空格分段，每段用独立会话（拼音模式 + 脚本自动识别），把各段首选拼接后与
期望整句比较；中文段是连续拼音，不按词切。

当前结果 **50/50 = 100%**。注意：语料与本轮实现同期手写，只能当冒烟门槛，不是独立基准；
真正的词内混排（一个词里中日交替）仍未支持。
