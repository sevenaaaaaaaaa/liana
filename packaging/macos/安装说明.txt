松萝（Liana）输入法 · macOS 安装说明
====================================

本安装包未经 Apple 公证（作者暂无 Developer ID 证书），从网上下载后 macOS 可能提示
「已损坏，无法打开」或「移到废纸篓」。这不是文件真的坏了，按下面几步放行即可。

一、安装（选一种，两种不要混用）

  推荐：松萝安装器 → 装到 ~/Library/Input Methods（不需要管理员密码）

  1. 把「松萝安装器」拖到旁边的「Applications（应用程序）」文件夹。
  2. 双击「打不开？双击我.command」。
     它会去掉 macOS 的隔离标记，然后自动打开安装器。
  3. 如果 macOS 连「打不开？双击我.command」本身也拦下：
     - 在它上面点右键 → 打开 → 再点「打开」；或
     - 系统设置 → 隐私与安全性 → 页面下方点「仍要打开」。
  4. 也可以不用脚本，在「终端」里执行这一行（效果相同）：

     xattr -dr com.apple.quarantine "/Applications/松萝安装器.app" && open "/Applications/松萝安装器.app"

  另一种：在安装器里勾「安装给所有用户」→ 装到 /Library/Input Methods（要管理员密码，
  适合多用户机器）。

  ⚠ 两种装法会在两处各留一份，输入法菜单里就会出现两条「松萝」。
    如果不小心都装了：删掉不需要的那份（系统级那份需要
    sudo rm -rf "/Library/Input Methods/Liana.app"），再跑一次自检（见第三节）。

二、启用（装完不会自动切过去，需要一次手动选择）

  1. 点屏幕右上角输入法图标（显示「拼」或「A」），列表里选「松萝」；
     图标不在就按 Control + 空格。
  2. 都没有时：系统设置 → 键盘 → 文字输入 → 输入法 → 编辑… → + → 中文（简体）→ 松萝。
     列表里仍然没有，注销并重新登录一次。
  3. 想设为默认：把「松萝」拖到输入法列表第一行，并取消勾选
     「自动切换到文稿的输入法」（不取消的话，每个 App 会记住各自上一次的选择）。

  列表里应该只有一条「松萝」。

三、自检（装完或怀疑装重了）

  终端执行（默认的安装器装的是用户级那份）：

    "$HOME/Library/Input Methods/Liana.app/Contents/MacOS/Liana" --verify-install

  如果装的是系统级那份，把路径换成：

    "/Library/Input Methods/Liana.app/Contents/MacOS/Liana" --verify-install

  它会逐项告诉你：装了几份、注册是否被写了两遍、菜单里有几条、是否已启用，
  每条不通过都会给一行可以直接复制的修复命令。
